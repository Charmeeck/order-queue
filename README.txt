ЛИСТ ЗАКАЗОВ — онлайн-админка

Теперь очередь можно редактировать прямо на сайте.

1. Откройте вкладку «Админка».
2. Пароль интерфейса по умолчанию: 1234.
3. Добавляйте, изменяйте и удаляйте заказы.
4. Нажмите «Сохранить на сайте».
5. При первом сохранении вставьте GitHub Fine-grained token.
6. Токен хранится только в sessionStorage текущей вкладки и не попадает в GitHub Pages.
7. После сохранения orders.json обновляется в репозитории CharMeeck/order-queue.

Для токена:
- Repository access: Only select repositories -> CharMeeck/order-queue
- Repository permissions: Contents -> Read and write

Важно: GitHub Pages остаётся статическим хостингом. Пароль 1234 защищает только интерфейс, а не является настоящей серверной авторизацией. Реальная возможность записи в репозиторий есть только у того, у кого есть действующий GitHub token.
