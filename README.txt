ЛИСТ ЗАКАЗОВ — версия с админкой

Админка:
1. Откройте вкладку «Админка».
2. Пароль по умолчанию: 1234
3. Можно добавлять, изменять и удалять заказы.
4. Изменения хранятся в localStorage этого браузера.
5. «Скачать JSON» создаёт новый orders.json. Чтобы изменения увидели все посетители GitHub Pages, замените старый orders.json в репозитории этим файлом и сделайте commit.

ВАЖНО: GitHub Pages не является сервером. Пароль в JavaScript нельзя считать настоящей защитой от просмотра исходного кода. Для реальной приватной админки нужна серверная авторизация и база данных.
