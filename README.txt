# Лист заказов — бесплатный сайт

## Что внутри
- `index.html` — страница сайта
- `style.css` — оформление
- `script.js` — поиск, фильтры и сортировка
- `orders.json` — данные очереди

## Как обновлять очередь
Открой `orders.json`, измени/добавь заказы и снова загрузи файл в GitHub.

## Важно
GitHub Pages публикует статический сайт. Данные из `orders.json` технически доступны тем, кто знает адрес файла. Поэтому этот вариант подходит для "только просмотр", но не для хранения секретной информации. Если нужна настоящая авторизация подписчиков, следующим шагом можно добавить бесплатную систему доступа.
